# Blender body-to-body impact QA fixture

Original first-party test geometry generated by `kumiki-blender`'s
`scripts/blender_physics_pair_contacts_smoke.py`, Blender 4.5.15 LTS.
This fixture is an integration test, **not** finished cinematic artwork.

- `model.glb`: three semantic Blender meshes (moving metal impact block,
  stationary stone anvil and distant wall).
- `baked-actions.json`: 30-fps PM2 transform track produced from actual Bullet
  evaluated motion, with **two** opt-in block-to-anvil contact candidates and
  **no** false block-to-distant-wall candidate.
- `physics-plan.json`: original declarative PhysicsShot plan.
- `manifest.json`: export audit and byte counts for the checked-in artifacts.

The `.blend` source is generated locally by the Blender-side smoke script and
is deliberately not bundled for browser playback. `source.blend` in the export
manifest refers to that unshipped producer artifact. Contact speed and timing
are derived from solver-sampled motion plus mesh proximity; they are **not**
native Bullet manifold or impulse measurements. No audio is bundled.

Reproduce: from `kumiki-blender`, run
`blender -b -t 2 --python scripts/blender_physics_pair_contacts_smoke.py -- <new-output-dir>`.
The checked-in sidecar is whitespace-minified; therefore its audited byte size
differs from the unminified producer output.
