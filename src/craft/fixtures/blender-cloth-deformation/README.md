# Real Blender cloth deformation test

First-party Blender 4.5.15 LTS fixture generated by the `kumiki-blender`
`blender_deformation_smoke.py` script and the generic `build-deformation`
worker. The producer scene is an 81-vertex cloth grid with one edge pinned,
evaluated by Blender's native Cloth solver for 24 frames at 30 fps.

- `model.glb`: actual sampled cloth vertex deformation stored as 12 standard
  glTF morph targets and a named native `cloth-sag` animation with one `weights`
  channel. This is not a procedural Three.js approximation or authored CSS.
- `manifest.json`: provenance, GLB/semantic audit and original byte counts.
- `deformation-plan.json`: bounded frame/mesh sampling configuration.

The editable `source.blend` includes Blender's original Cloth modifier and is
generated by the upstream script; it is not bundled in a web fixture. The
source file named in `manifest.files.source` refers to that unshipped artifact.
The sampled 81-vertex grid is **functional QA geometry**, not a production
fabric texture or cinematic cloth model. No audio or licensed assets bundled.

Reproduce in `kumiki-blender`:

```bash
blender -b -t 2 --python-exit-code 1 --python scripts/blender_deformation_smoke.py -- <new-output-dir>
```
