# MG1 verification and mask rendering — 2026-10-17

## Scope and outcome

This run follows roadmap **V1** before adding another media subsystem. Existing MG1 components,
storyboards, infographic code and composition stories were inspected; they were not rebuilt.
The long-term target remains parameterized 2D/3D productions with character and camera tracks,
authored framing per output aspect, and reproducible export through optional adapters.
This increment addresses a concrete prerequisite: the same authored mask must render consistently
in standalone React reveals and coordinated SVG compositions.

`GraphicComposition` previously drew the pre-transform mask rectangle and dropped feathering.
It now shares `registry/motion/svg-mask.tsx` with `MaskRevealView`: resolved polygons, explicit
user-space bounds, hard clips, alpha/luma opacity and padded Gaussian feathering. A feathered clip
uses an alpha matte. Native CSS `mask-type` replaces the unrecognized React `maskType` attribute.
No third-party package, public prop, timeline schema or registry item was added. The internal file
ships with the existing `motion-react` item. Fixed composition layout/target names remain as
documented in its spec; this is not a generic scene renderer.

The new browser test also exposed a showcase defect: a default `false` context overrode the system
reduced-motion preference. The gallery now combines system preference with its explicit preview
toggle; when the system requests reduction, the checked toggle is disabled with an explanation.
Changing the system preference live is covered.

[CSS masking](https://www.w3.org/TR/css-masking-1/#propdef-mask-type) and
