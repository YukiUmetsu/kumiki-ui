# RISO31 — ArtCraft: anatomical finger bending that actually prints

**Primary output:** original Courier and Paper Artist hands (both left and right), in the existing Risograph illustration/Storybook and the same 240-frame physical two-spot-ink film. This is a RISO31 continuation of [RISO30 source hand research](riso30-anat1-hand-print-artcraft.md). No new Storybook folder, photographs, raster filters, opacity tricks, or removal of microdetail.

## Authentic external references (deconstructed, not imported)

- David Vanadia, **Liens Tissés**, actual Risograph interwoven fingers (photographed and discussed by [Creative Boom](https://www.creativeboom.com/inspiration/david-vanadias-bold-and-minimalist-illustrations-that-fuse-graphic-design-with-art/)). **Continuity:** five full digit roots, tightly overlapping finger crossovers, meaningful paper-white negative-space tunnels. **Vector flow:** palm-to-fingertip root curves, not four parallel flat stripes. **Weight:** broad metacarpal/palm supports taper into flattened fingertip pads. **Rhythm:** alternation of solid fingers and white pressure seams. **Texture:** deliberate physical cobalt deposition. Study only, do not duplicate copyrighted geometry.
- Jennifer Colquhoun, **Fingers Crossed Anatomy Risoprint** ([print listing](https://harp-cowbell-wcet.squarespace.com/shop/p/fingers-crossed)). **Topology:** index/middle crossing at distinct bent knuckles, dorsal tendons survive open lines and layered pigment. **Material:** paper + separately printed blue/red/yellow pigment, true anatomy vocabulary. The new library uses original two inks only; this image is a reference, not a source asset.
- [Ergonomic Evaluation of Biomechanical Hand Function](https://pmc.ncbi.nlm.nih.gov/articles/PMC4372184/), Chao et al. functional task angles (tip pinch MCP ~48°, PIP ~50°, DIP ~25°). This is **3D anatomical flexion**, not how many degrees an illustrator should rotate a 2D picture.
- Actual canonical **Kumiki ANAT1** `registry/anatomy/anatomy-pose.ts` `JOINTS`, `HAND_POSES.pinch(".R")`. Specifically real finger2–finger5 PIP/DIP clinical ranges/poses. The new source uses only 36% of that clinical pinch bending as **stylized projected 2D angles** (and 66% of that ratio for DIP), to avoid bent-digit self-intersections. Never claim clinically accurate portrait projection.
- Real production baseline: [RISO30 physically printed 5-finger original artwork](../../src/video/riso-hand-artcraft.ts), [source character rig](../../src/video/riso-character-demo.tsx), [two-human film](../../src/video/riso-human-ensemble.tsx), and [RISO30 rejected screenshots/corrections](riso30-anat1-hand-print-artcraft.md).

## Five-axis deconstruction / actual source changes

| Axis | Original RISO30 defect | RISO31 source change |
| --- | --- | --- |
| 1. Topology and isolation | Four original long fingers had only one MCP-to-nail red path. Creases gave the *appearance* of joints but the fingertip did not actually bend; DIP nails could float off a newly bending print. | True **MCP → PIP → DIP** joint parent tree, 4 non-thumb fingers × 2 new pivots × 2 original actors × 2 sides. Every source finger now has **three red printed sections**. Thumb retains its own independent ANAT1 root (thumb IP is a distinct future task). |
| 2. Vector flow | Parallel stripes from MCP to tip, no change in axial direction at bent paper contact. | PIP and DIP each rotate independently in the existing deterministic 240-frame source; signed fanning depends on side/index/middle/ring/pinky and actual `HAND_POSES.pinch` values. C/Q contours curve from living proximal to intermediate and narrowed distal phalanx. |
| 3. Volume and negative space | A hard cut between red segment shapes would introduce a gap or a black knuckle in the physical 2-plate renderer. | Red phalanges have **2.4 source-unit overlapping rounded caps** and tapering, asymmetrical ink shapes. Preserve the existing entire palm, thenar plane, blue wrist seam, forearm skinning, red thumb, independent side identities. |
| 4. Temporal action | RISO30 f160 paper pinch had five red fingers but no actual PIP/DIP movement. | Source keys on new joints at f0, 96, 126, f160/f166 contact, f180/f186 partial release, f205, f239; calm rest → individually bent tips → release. Source paper, hand contact x/y, root pelvis, foot IK, and film 16:9/9:16 chronology remain unchanged. |
| 5. Tactile engraving | Previous nail-bed rims / PIP + DIP blue marks were anchored to the old rigid MCP joint and would detach if bent. | Tiny original blue crescent nails **retargeted to each real DIP joint**; original dual PIP crease grammars now at PIP; **four additional DIP-local ink-engraving parts** per hand. No RGB layers, no photo, no gradients or regenerated media. Cobalt marks print over real vermilion finger mass and over the physical letter when that finger is in front. |

## Code / production integration

- `src/video/riso31-finger-phalanges.ts`: `riso31PhalanxJoints`, `riso31FingerParts`, `riso31Inspect`, typed geometry constants and hand source-pose mapping. Three actual source-region parts per index/middle/ring/pinky; no new dependency.
- Original Courier rig references the new source joints directly; Paper Artist inherits exactly the same physical 2D rig bone topology but preserves own independently authored 18 blue/red hand-engraving parts per side and distinct costumes/face.
- The receiver's physically printed letter foreground includes both new red phalanx sections and original blue DIP nail/joint marks. Previous source still owns all letter clocks and occlusion rules.
- `risoHandArtcraftParts` keeps all original 14 items and **adds 4 separate DIP creases**; nail positions and existing PIP engraving now use actual moving source bones.
- Original `RISO_COURIER_SHEET` plus automatically derived `RISO_PAPER_ARTIST_SHEET` expose PIP/DIP source regions for silhouette and topology QA; `layoutRisoHandArtcraft` includes all posed PIP and DIP extrema before choosing the safe physical-print crop.
- **Same Storybook page:** extended 0/46/126/144/160/166/178/186/198/239 source frames, original dual cobalt/vermilion spot separation, screen density, zoom, mirrored original actor hands. Native per-hand `data-km-riso31-actual-flexion`, segment count and source crop attributes enable actual browser regression evidence.

## Release gates / limitations

1. **Structural:** `npx tsc --noEmit`; `tests/riso31-phalange-artcraft.test.tsx` evaluates every even source frame against real actor PIP/DIP lengths, red source part names, independent clinical-limited transforms and named overprinted ink. Older RISO28–RISO30 continuity tests must remain passing.
2. **Chromium native print:** review f0, 46, 126, 160, 166, 178, 186, 198 (original authors' both actors), each red/blue isolated plate and physical final handoff in **16:9 / 9:16**. Reject disconnected distal tip, violet thick overlap, overextended joints, missing thumb, fake gradients or cropped moving fingers. Playwright screenshots are measured evidence; **passing tests alone do not certify beauty**.
3. **Remaining:** original graphic faces are still frontal-2D and not a photographed reference identity. Thumb IP needs genuine articulating source segments and visually verified opposed pinch, not a painted extra line. Future face views require licensed front, 3/4, side reference sets and independent ArtCraft anatomy/fidelity gates. No unobserved angle should be "certified realistic."
