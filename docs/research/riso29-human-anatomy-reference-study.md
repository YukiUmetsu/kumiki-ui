## Actual sources and visual observations

1. **Original production source:** [RISO28 24fps film](../../src/video/riso-human-ensemble.tsx), its real [face/limb paths](../../src/video/riso-character-demo.tsx), and actual Chromium f0/46/160/198 printed screenshots from PR #415. Both characters had **heads wider than the articulated shoulder span**, disproportionately large caps/hair relative to legs, and **chins resting directly against high shirt/coat collars**; an existing rectangular blue "neck" was covered by the same face. At final size the red speaking mouth resembled a red oval dot, without its upper/lower lip grammar.
2. **Anatomical understructure**: [ANAT1 registry](../../registry/anatomy/README.md), [human body construction measurements](../../registry/anatomy/anatomy-measure.ts), [canonical MediaPipe eye and lip loops](../../registry/anatomy/anatomy-face.ts), and [graded drawing canons / sternomastoid, clavicle surface anatomy](../../registry/anatomy/anatomy-reference.ts). Source grade S MakeHuman adults average 7.59–7.78 heads tall (population *model*, not proof of any individual portrait), while adult reference photos can be measured separately. ANAT1's cervical bones, mouth loop, upper/lower eyelids and visible sternocleidomastoid **inform** the source construction. The old original authors never supplied an approved identity sheet, so reference matching cannot be claimed.
3. **Actual printed portrait style reference:** Ryan Putnam, [Self-Portrait Experiments](https://ryanputn.am/sefies) — Riso-limited editorial portraits, strong non-circular face silhouettes, deliberate focal ink and hair shapes; source is style guidance, **not** face to duplicate. Taylor Blessing, [Risograph Portrait](https://www.taylorblessing.com/illustration) — preserve bold facial midtone separation under limited ink plates.
4. **Secondary original process study:** Mayumi Tsuzuki [People of Print profile](https://peopleofprint.com/disciplines/illustration/mayumi-tsuzuki/) — controlled black-and-white masters per ink and purposeful hand-drawn texture, **not** a mandate to represent all skin tones with freckles. Conor Stechschulte [Character Risograph Print](https://www.conorstechschulte.com/artwork) — variation in character silhouette and editorial expression inside same print limitations.
5. **Existing evidence:** [RISO28 source and QA](riso28-grounded-arrival-artcraft.md), [RISO26 graded physical master](riso26-tonal-master-artcraft.md), [RISO13 ArtCraft 2D source mesh](../../src/video/riso-character-mesh-sheets.ts). Existing front-facing figure is not a true 3D side/3/4 person.

## ANAT1 mapping used in code

- `RISO29_ANAT1` reads the actual `MODEL_TABLES.byAge.male` adult *model-derived* mean, `FACE_LANDMARKS`, four different `FACE_FEATURES` eyelid loops, and `SURFACE_FORMS` region `neck` from `registry/anatomy/`.
- `inspectRisoAnatomy` computes *posed* actor head-to-shoulder ratio from actual `evaluateRisoCharacter` matrices and validates true connected parent joints and face part count. This is a **source geometry** gate, not a face-quality score.
- `risoAnatomicalNeckParts("courier"|"paper-artist")` produces independent editable anatomy-specific source outlines. Their code owns no new 2D renderer, timeline, wall clock, or arbitrary skin color.
- New `HumanAnatomyNeckPortrait` Storybook story **in the existing Risograph folder** uses physical `RisoPrint` spot masters at full-body and 4.05× real head+neck crops with actor, expression, blue/red master, screen density and rig diagnostic controls.
