# RISO70 — Actual print-shop profiles and independently anchored scanner proof

**Scope.** An explicit paper-feed, grayscale-master and physical registration measurement lab. The example numbers are fictional operator-editable defaults, not specifications or tolerances of any named printer. No physical scan has been provided, so no physical print or press calibration has been proven. The original two native RISO66–69 master geometries and their original paper-open dry-brush holes are untouched. No human-hand work.

## Authentic print-shop research and material deconstruction

- RISOTTO Basic Risograph Print Setup: https://risottostudio.com/pages/basic-print-setup . Requests grayscale PDFs, notes no need to include registration/crop marks and describes possible physical 2–3mm registration shifts. These dimensions and policies are specific to their operation, not global machine defaults.
- Risolve Studio File Set Up: https://risolvestudio.com/pages/file-set-up . Asks for grayscale PDF separations at 300–600 PPI; full bleed requires approximately 1/8 inch of artwork beyond trim. Some shops require full-bleed trim policies that conflict with others.
- MICA Risograph File Prep: https://www.mica.edu/campus-life-and-resources/places-and-spaces/maker-spaces-fabrication-studios/printmaking-studio/risograph-file-prep/ . Calls for 1/4-inch margins in its own shop, unique grayscale masters per ink and attention to registration of fine multicolor marks.
- SAIC Service Bureau: https://sites.saic.edu/servicebureau/home/services/risography-printing/ . Describes machine-specific unavailable border and physical paper restrictions. A generic symmetric print-safe inset cannot describe every feed configuration.
- Spectrolite Settings: https://spectrolite.app/how-to/using-spectrolite/preferences . Exposes actual user-adjustable print-area, leading paper edge, mark policies, and DPI settings; never hardcode a manufacturer-specific unprintable zone without shop/user confirmation.
- RISOTTO Advanced Setup: https://risottostudio.com/pages/advanced-print-setup . Grayscale source determines deposited spot ink density, and microscopic edge/paper pickup patterns differ between physical stocks; a synthetic RGB color proof cannot establish real register accuracy.

**Source topology:** Original long and short source-pressure bristles retain their entire authored cubic/quadratic flow and independent negative-space paper openings. RISO70 never shifts, rasterizes or morphs an existing physical spot ink to "repair" a numerical scanner registration mismatch. The same RISO68 path parser measures real native vector geometry; the PDF/TIFF exports continue through RISO69's independently checked monochrome contracts.

**Physical vector and material:** Source SVG art, K density, paper-white holes, trim grid and registration-cross geometry share a deterministic millimeter coordinate system. For each independently declared paper profile, a geometric audit checks actual source contour samples, all 16 optional crop/register line endpoints, trim plus configured bleed against all FOUR potentially asymmetric printer margins. Failing any bound suppresses the file download rather than silently clipping or moving a stencil.

**Observed scan geometry:** A useful physical comparison MUST not fit its reference transform to printed colored marks, because doing so could erase the drum's true registration offset. Four actual PAPER corner pixel coordinates determine a least-squares affine sheet-mm-to-scan-pixel transform and its inverse. Each drum then supplies exactly four measured physical cross centers, top/bottom/left/right, in scan pixels. Each cross position maps back to physical mm and yields signed x/y error, norm, per-drum mean, RMS and worst mark deviation. Each pair of ink drums yields independent relative average x/y displacement and worst matched-cross error. This proof is only as authentic as the operator-supplied measurements; report operator-measured input, NEVER an externally authenticated scan or certified press.

**Perspective limits:** Four-corner paper affine scan calibration covers global crop, rotation, shear and scale. Large perspective or lens distortions produce non-affine corner residuals; fail closed above the explicit 0.5-mm default scanner residual. Do not use this to correct unknown curved/folded stock; flatten the sheet or perform a separately validated higher-order calibration.

**Provenance and time:** Synthetic demo coordinates derive from a rotated 12-pixel-per-mm scanner model with explicit red-drum simulated drift. They are always tagged simulation-only. A downloadable JSON measurement template contains null observed paper corners and null cross centers. Real proof requires manually filling ALL 12 measured scan-pixel positions from an actual sheet, per frame/seed, from actual printed passes. No OCR, photo upload or physical data invention is performed. A printed sheet must be measured and the printer/paper/ink/scan device recorded before making real calibration claims.

## Public API and review surface

- registry/video/riso-shop-profile.ts: RisoShopProfile and inspectRisoShopJob. Bounded explicit shop data including sheet orientations, four independent unavailable margins, feed direction, PDF/TIFF/PPI acceptance, crop/register mark policy, min/max bleed and profile provenance.
- registry/video/riso-scan-proof.ts: risoPrintRegistrationTargets, createRisoScanTemplate, simulateRisoScanProof, inspectRisoScanProof. Independent paper-corner affine, mark comparison, pairwise drift, strict input rejection.
- Storybook Video production → Film Looks → Risograph → Printer Profile and Scan Registration Lab. Two complete source-native independent ink masters, 1×/2×, landscape/portrait and arbitrary original source frame; asymmetric margins and source-only PDF/TIFF downloads; synthetic versus manually supplied actual scanner pixel readings, numeric status and strict blockers. No new dependencies.
- Mandatory gate: strict TypeScript, focused original RISO65–RISO70 tests, clean consumer registry, Storybook Chromium screenshot proof and real PDF download/Poppler render, explicit rejection of unsafe paper geometry, malformed scanner measurements and physically inconsistent paper corners.

## Outstanding physical limitations and next step

The sample A4 print profile with top 10mm and other edges 8mm is illustrative, not validated for any manufacturer. The stamp/cross positions and brightness of native grayscale files are not proof of machine color response or stock; the print shop may want PDF, TIFF or additional file controls. Real print scans are necessary for actual physical QA. A flatbed scan with documented paper edge positions and both drum cross centers is the next empirical step. Do NOT work on human-hand PR #513.
