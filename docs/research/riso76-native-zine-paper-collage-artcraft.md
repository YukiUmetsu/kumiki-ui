# RISO76 ArtCraft — Original torn-paper, print-to-print zine collage

## Material source study (real reference imagery, no artwork copied)

The new scene is a **paper-collage film transition**, not an attempt to simulate a scanner. Existing `RisoSheetFeed` turns a fully rectangular printed sheet; `RisoOverprintTransition` stamps ink to bridge scenes. Neither can recreate the **continuously chipped, thick and fibre-fissured silhouette of a torn sheet of paper**, which is characteristic of tactile cut-paper zine collage.

**Source-image references (external only, no assets bundled):**

- **Hato Press — If We Run Together, photographed riso zine:** https://www.behance.net/gallery/149578473/Hato-Press-Zine-If-We-Run-Together ; [published photographed print image](https://mir-s3-cdn-cf.behance.net/project_modules/1400/ba239a149578473.62ea193531c6e.jpeg). Distinct saturated pink/yellow/blue and near-black shapes, jagged *printed* color boundaries and narrow paper openings. Some irregular edges are a printed collage aesthetic, not evidence of a physically ripped sheet. Keep ink channels intact.
- **Rhianne Connelly — Collage Riso Repeat:** https://rhiannemargo.design/collage-riso-repeat-1 ; [independent photographed printed sheets](https://cdn.myportfolio.com/d90a558b54c6b333014cae339049d152/f7cbb922-5ff7-45e5-9771-38bad19dbd45_rw_3840.jpg?h=ae91d21e1ca526f18eb44164fab21b42). Transparent vermilion/teal overprint, rough screen texture, newspaper-white substrate and repeated original screen marks.
- **Sunroom — Risograph Scraps Zine ’21–’23:** https://www.hellosunroom.com/archive/2024/2/7/risograph-scraps-zine-21-23 . Genuine physically bound zine: two confronting paper pages and strong saturated ink channels. Provides a grounded printed-sheet scale context, **not** an image of a torn edge.
- **People of Print — printmaker Michael van Kekem’s Riso Zine:** https://peopleofprint.com/illustration-2/michael-van-kekem-riso-zine/ . Artist explicitly makes cut-paper shapes before converting them into several printed layers. Ink geometry is *authored* rather than generated by filtering a photo.
- **Museum of Modern Art — *Printed, Cut, Folded and Torn*:** https://www.moma.org/momaorg/shared/pdfs/docs/press_archives/5117/releases/MOMA_1974_0048_42.pdf . General printmaking material context for physical tearing, cut/crease work and tactile paper surfaces, not specific measured Risograph print samples.

These sources justify the **printed zine/collage design vocabulary**. They do not constitute calibration of tear mechanics, genuine user-owned paper fibres or any particular machine feed; do not claim physical testing. Original full-color artworks are NOT copied/traced/downloaded or bundled. No human hands are drawn.

### Five non-negotiable artistic axes

| Axis | Visible reference logic | Native implementation |
| --- | --- | --- |
| Shape/topology continuity | Distinct print areas must stay drawn as real, complete shapes, not filtered bitmap fragments. | Two original ink separation drawings preserved as separate `RisoPrint` SVGs; new paper only uses `<clipPath>` of the incoming sheet. Source ink contours, internal paper-negative openings and readable editorial type remain unchanged. |
| Vector flow | Paper tear follows a continuous physical travelling boundary, with longer bends and small abrupt splits. | 129 continuous hand-weighted procedural original edge stations blend broad tension waves, mid-scale irregular shifts and cellulose micro-serrations. Fixed seed never changes with frame. |
| Edge micro-elements | A ripped sheet has a thin shoulder with protruding cellulose threads, fine darker exposed side, contact shade. A digitally masked straight wipe is insufficient. | 144 independently seeded, thin *curved* splinter paths, layered paper-lip highlight, close contour shadow, broad substrate shade. Edge is a real continuous polygon in original page coordinates, not a screen-space CSS filter or white-painted background. |
| Source layering | Printed zine pages and overlapping spot-ink artwork are different material layers. | Keep full outgoing and incoming original two-drum prints, paper layers and colors. Moving top sheet clips only itself. Incoming sheet overlays outgoing at the tear with physical contact shading; original `RISO75` per-drum irregularity can be used independently. |
| Temporal/optical depth | Moving paper edge makes the typography underneath disappear without ghosting while the ink and halftone stay stable. | Only the paper tear boundary changes with frame. Original dots, paper grain, spot plate registration and retained source vectors stay static. A single original 24fps `FilmStage` controls the film, with three authored shots and 16:9/9:16 outputs. No second clock, raster filter or image crossfade. |

## Component contract (proposed → implemented)

- **Name:** `RisoTornPaperTransition` + `createRisoTornPaperProfile`, `risoTornPaperShape`, `risoTornProgress`.
- **Use:** Cinematic original printed editorial zine, printmaking collage, physical torn-page scene change. **Not** for a generic opaque digital wipe, scanner/press calibration, copied photos, or where the director needs a perfectly matched uncropped source frame.
- **Public props:** `outgoing`, `incoming` (independent `RisoSheet` composed of source SVG ink masters), absolute `frame`, `startFrame`, `durationFrames`, direction (L→R, R→L, T→B, B→T), paper `seed`, `roughness` [0–1], `paperThickness` [0–1], `misregistration`, `paperGrain`, `drumContact` (RISO75 opt-in), `reducedMotion`, `label`, `className`, `style`.
- **Dimensions:** Two actual page outputs must be equal in width/height, but page paper color may differ for a collage of different stocks. Portrait and landscape have different separately authored original `risoExampleArtworks` and `risoSecondSheetArtworks`.
- **Visual states:** 0 = only outgoing print, 0–1 = two source prints separated by physically shaped edge (with 144 splinters), 1 = only incoming print. `roughness=0` removes each splinter and macro jaggedness for blade-cut pages; `paperThickness=0` minimizes relief but does not deform source art. Every direction, film frame, full-grain and registered ink remains art-directed.
- **Accessibility:** One labeled `role="img"` SVG, child source prints hidden from duplicate screen readers; intentional print-text clipping marked as such. Storybook uses native buttons, selects, and labeled range inputs, with keyboard/home/end, accessible text and exact reduced-motion still.
- **Production:** The same `RisoTornPaperTransition` runs as `renderSlot` in `FilmStage`; original FD1 file `src/video/riso76-collage-film.ts` has 52 frames of original print I, 120 frames of collage, 60 frames of completed original print II; 24fps, no other clock. The first and last frames are exact, no overlapping text ghosts or bitmap/dissolve.
- **Performance/privacy:** 129 original edge stations; 144 thin curved fibres only when edge active. 1 set of seeded deterministic source paper coordinates per render; no remote assets, network requests, third-party fonts, image generation, global RNG, WebGL or new runtime packages.
- **Known limits:** vector-drawn physically *plausible stylization*, not actual scanner image/fiber length measurements. Needs artist review against owner-provided actual torn printed samples before any empirical realism claim.

## Release gates and screenshot sign-off

1. Strict `npm run typecheck` and `npm run test -- tests/riso76-torn-collage-artcraft.test.tsx`; original RISO62/63/68/69/75 tests must not regress.
2. Run `npm run registry:validate`, `node scripts/registry-fixture.js --item=riso-print`; both geometry modules and React composition must resolve cleanly in an independent consumer.
3. Run `npm run build-storybook` and actual Chromium `tests/e2e-storybook/riso76-native-paper-collage-film.spec.ts`: source one, midpoint both separately inked, 144 fibres, four directions, zoom/no texture crawling, 9:16 original output, zero roughness, terminal frame continuity, reduced motion, no browser exceptions.
4. **Visual QA:** Compare actual 1× opening and 3× cut edge screenshot; look at the fibrous silhouette and thin physical paper shoulder, typography visibility/clipping classification, double-printed contrast, dual drum regularity, positive/negative paper scale and portrait cut. Reject layout collisions, floating/unattached splinters, unrelated random dots, overstrong shadow or unreadable source type.
5. **Remaining art hold:** These are authored optical shapes informed by photo references; physical signed-off paper realism requires actual torn Risograph print samples photographed macro at the same scale. CI success is technical evidence, not material certification.

The primary output is an **artistic visual transition component** for rich cinematic reuse, not another press quality dashboard.
