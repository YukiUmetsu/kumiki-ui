## Five-axis structural / material model

1. **Topology and continuity:** keep actual source actor → opaque printed letter → **only** 3 independently moving red index phalanges and 3 independently moving blue nail / PIP / DIP creases. The source actor already includes both true red thumb IP shapes and the other nine red support phalanges, still living and moving behind letter. No deleted model parts, no opaque second cartoon thumb sticker.
2. **Vector flow:** actual source red and blue paths, pivots, easing, bone lengths, and ANAT1 constraints stay unchanged. New z-order does not redraw/flatten gradients or any micro-element. The letter edge itself still follows original RISO40 true opposed source-index/thumb midpoint, and its RISO41 physical pressure responds to the actual red-pad gap.
3. **Weight and depth:** ink opacity on the physical opaque letter, not CSS transparent compositing, separates opposed pads. The index prints on both actual red and blue spot masters, its blue nail and folding engravings remain registered to its true moving DIP/PIP. The underlying thumb inherits existing full original ink and paper knockout.
4. **Rhythm and release:** 0–239 original 24fps frame source. At f160 and f166, the donor and receiving index overlays exist only while real sheet contact is authorized. Donor foreground is removed after true released red pad separation; receiver remains holding through f239. The 16:9/9:16 source layout, paper tilt, gait, and original relative chronology remain.
5. **Microtexture:** original grain/fibres, misregistration, two independent `RisoPrint` screens, rich C/Q anatomy contours, red flesh-pad shape, blue nail lunula, intrinsic rough edge character all kept untouched. No Gaussian blur, new color plate, CSS opacity-faded mitten or raster replacement.

## RISO44 independently measured print-ink/letter intersection — actual source, not a DOM count

The original RISO43 full-film Chromium f160/f166 prints were inspected directly, including a 4× crop of the left/right paper endcaps. **Observed**: the three receiving support digits still extend beyond the paper on the upper radial side and the donor fingers form a small hooked cluster. Merely counting 3 source index RED and 3 BLUE SVGs in an overlay layer is insufficient to verify that they actually intersect the paper. Those parts may exist but float in paper-white space.

**RISO44 physical-print QA** therefore samples the *actual evaluated closed source SVG ink contours* in their final figure stage coordinates and the true independently curved, pinched paper contour. It measures minimum Euclidean WHITE distance from each printed RED index region to the letter, and tests edge crossing, containment and genuine source area overlap, without raster masks or fixed rectangular hitboxes. Results are recorded for both original actors and both aspect ratios, on every selected contact/release proof frame. Blank/unfurl source appropriately returns no intersection. A deliberately distant fake letter is rejected. Native Chromium asserts both printed index pads actually intersect the moving page at f160/f166; a physically disconnected finger now fails even when every source ink part exists and the UI still says "shared".
