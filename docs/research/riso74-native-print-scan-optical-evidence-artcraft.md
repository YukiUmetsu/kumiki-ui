## Five medium-specific structural constraints

1. **Continuity of original stencil topologies:** RISO68–73 closed native vector ink contours and their evenodd paper-negative fibers remain byte-identical. The diagnostic panel does *not* reroute, simplify, vectorize, denoise or recolor them.
2. **Vector flow:** Directional pressure strokes and tapered ends remain independent of the rotating photographic pixel grid. Paper-corner affine transforms, never color-edge image matching, determine physical millimeter alignment.
3. **Ink edge characteristics:** Real print registration ghosts, microdots and paper cavities may appear in genuine scans, but cannot be asserted from blurred, small or generated raster images. No sharpen, interpolation, or "grain" filters create evidence.
4. **Layer-specific optical depth:** A color scan of an overprinted print is not a grayscale stencil, a calibrated per-drum absorption measurement, or a physical overprint transmittance curve. Browser RGB values are uncalibrated, affected by acquisition lighting and JPEG artifacts.
5. **Material microstructure and scale:** The original *natural pixel* scanner resolution determines whether detail exists. Scaling a browser DOM preview by 3× changes only the apparent size; it cannot restore a paper fiber or individual spot halftone site that wasn't sampled.

## Implementation

- `inspectRiso74NaturalPixelDensity` computes the **minimum singular value** of the original *paper millimeters → original natural image pixels* 2×2 matrix, then multiplies by 25.4 to calculate **worst-direction effective pixels per inch**. Anisotropic image stretching cannot inflate this score; the source image may still be defocused or resampled. This PPI is a geometric **upper bound on sample density**, not optical resolving power.
- The panel reports below-300 PPI, 300–599 PPI and 600+ PPI input sampling classes for **each** image, with non-certifying language. 300 PPI is a pragmatic warning boundary, **not** a claimed threshold for all possible machine screens. Many physical screen angles, frequencies and photographic capture settings differ by job.
- An artist controls the **physical location** (10–90% X/Y of the independently rectified paper) and a 2/4/8 mm physical square. Identical physical square on each uploaded original photograph is displayed at large size, using pixelated nearest-neighbor rendering to expose insufficient native detail rather than inventing smooth dots.
- Each browser-owned image is locally decoded in a 16–128px small, nearest-neighbor Canvas sampling buffer. For underresolved scans, multiple grid cells repeat the same natural source pixel; diagnostic grid point counts must never be called distinct original pixels or authentic halftone cells. Native photo-to-paper affine reprojects the selected square. The sampling buffer is **for observation only**; nothing is rasterized into the source stencil, user's image or FilmStage.
- The raw RGBA pixel arrays yield mean RGB, mean luminance, luminance standard deviation and **independent horizontal/vertical adjacent-sample contrast**. These are objective pixel values *for the current photograph*, **NOT** spot-ink density, screen-cell count, coverage, blur identification, press calibration or perceptual color difference.
- The panel is inside the existing RISO73 two-photo Storybook; photo object URLs are provided only by the existing user upload component. No new runtime dependencies, external transmission, resource fetching, RGB source modification, permanent image storage or changes to the exported press PDF/TIFF masters.

## Explicit release tests and realistic caveats

1. **Mathematical:** 297×210 mm paper affine, 43.4 input PPI browser fixture rejected for dot-level evidence, positive 600 PPI rotated scan, 300–599 PPI intermediate, stretched 600×210 PPI photograph classified by *lower* singular value, invalid/reflected/singular geometry fails closed.
2. **True pixel values:** controlled 16×16 black-white line swatch has average luminance 127.5, contrast 255 horizontally but zero vertically and standard deviation 127.5. Uniform white/near-paper swatch remains zero spatial contrast; missing alpha and unsupported swatch sizes reject.
3. **Browser:** real original 508×360 screenshot of actual native RISO68 SVG is uploaded as a **synthetic source image** in each of two photograph input components. Its native PPI warning must display at 1×/3× and prevent false 600 PPI claims. Original PNG is locally decoded and sampled; the 2mm area is selectable via keyboard, with photographic crop and statistics visibly inspected in screenshots.
4. **Regression:** same original grayscale native stencil shapes, dry-fiber openings, original RISO70–73 registration QA, physical PDF/TIFF generation and Poppler independent PDF extraction remain intact.

**What is NOT established:** Physical ink-dot appearance, real photographic microstructure, paper fiber realism, scanner optical resolution/MTF, cross-capture color differences, manufacturer tolerance, person/hand anatomy, or production-quality Risograph art. Approval requires a pair of owner-supplied **actual** Risograph prints, unchanged 600-PPI-equivalent native samples (where practical), realistic print-shop stock and master settings, matching source contours and an independent artist's 1×/3× visual comparison. Do not infer photo-based fidelity from any simulated screenshot.
