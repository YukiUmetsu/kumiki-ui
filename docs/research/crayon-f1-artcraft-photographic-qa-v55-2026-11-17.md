# ArtCraft V55: original CC0 photographic source-vs-native evidence

**Research quality gate, not a visual component.** Original photograph Christopher Campbell CC0 [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Brunette_woman_portrait_(Unsplash).jpg); source is the **original 608×1082 browser screenshot** captured in [existing real-source artifact 14148787169](https://github.com/YukiUmetsu/kumiki-ui/actions/runs/43682633614/artifacts/14148787169), exact SHA256 `f8d28cbede8c8c14f9902a328b6e979e353fd9ebe6efb454bda3152586b929c2`. This is **not** the original high-resolution camera JPEG.

Problem addressed: V51 and V53 were technically passing but visually **worse**, because CI only asserted relative image difference and geometry. V54 passed technical/Chromium checks, but lacked independently reproduced source SSIM. V55 adds source-vs-actual-pixels to the existing targeted crayon proof, with **no photo embedded into shipped CRAYON1 render** and no Storybook user-facing photo view.

The workflow recovers the existing frozen photographed source from GitHub Actions (temporary ~14MB artifact, retention-limited), *fails closed* if no file has the exact source SHA, then renders original V52 and experimental V54 in the same Chromium 608×1082 camera, seed, physical paper and frame 299. A separate Chromium canvas decodes original photo PNG and both actual screenshot PNGs. Native 7×7 RGB/3-pixel-stride uniform-window SSIM (unbiased covariance) and full ROI RGB MAE are reported for whole source, eyelid, eye, iris, lower lid, face, crown and protected far-eye/upper foliage, with native pixel-change masks and exact SHA. This *sampled SSIM is not numerically equivalent to skimage full pixel SSIM*; use its paired scores consistently, not cross-instrument absolute scores.

**Review policy:** Green engineering test indicates valid artifact/evidence, **not artist approval**. The JSON report records `VISUAL_REVIEW_REQUIRED_OR_REJECT` if global source/upper lid fail to improve or original iris/lower lid regress more than .002. V54 can only be promoted after independent human review and same-metric source gain. Retain rejected V53/V51 as !dev only; the structural ArtCraft SSIM target .85, actual painted 18 landmark audit, five contiguous value planes and full-film human approval are still blocked.

**Maintenance:** the source artifact expires; while it is available, migrate the exact rights-verified CC0 source screenshot to a durable pinned test-only fixture, with checksummed provenance, or regenerate identical camera crop and update source SHA/gate explicitly. Never silently substitute an unregistered live JPG. If artifact unavailable, test fails instead of claiming photo equivalence.
